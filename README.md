Built an AI Network Traffic Analyzer that runs locally on macOS using Python, FastAPI, Wireshark, and PyShark. This project analyzes saved packet capture files from Wireshark, extracts network traffic features such as protocols, IP addresses, ports, and packet sizes, and uses anomaly detection to identify unusual traffic patterns. I also created a local web interface where users can upload .pcap or .pcapng files and view traffic summaries, security notes, flagged anomalies, and sample packet data. This project helped me gain hands-on experience with network traffic analysis, packet capture, cybersecurity monitoring, Python development, and applying machine learning concepts to security-related data.
